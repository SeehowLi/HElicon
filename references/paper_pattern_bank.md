# Paper Pattern Bank

This file stores distilled lessons from individual selected papers when they add distinct value beyond the unified patterns.

Use it for:

- unusually strong introductions;
- title/abstract structures worth imitating;
- evaluation narrative patterns;
- related-work contrast patterns;
- cautionary examples;
- venue-specific writing moves.

Do not store copied paragraphs or long verbatim text.

## Entry template

```markdown
## Paper: <short title>

- Venue/year:
- Area:
- Why selected:
- Core problem:
- Bottleneck framing:
- Key insight framing:
- Contribution structure:
- Abstract/title lesson:
- Introduction lesson:
- Evaluation narrative lesson:
- Terminology worth reusing:
- What not to imitate:
- Relevance to user's future papers:
```
