# Direction Pack Template

Create reusable direction packs outside the skill:

`HElicon_workspace/direction_packs/<direction_name>/`

Recommended files:

```text
direction_brief.md
focused_paper_patterns.md
direction_glossary.md
baseline_expectations.md
threat_model_notes.md
evaluation_playbook.md
open_questions.md
```

## direction_brief.md

```markdown
# Direction: <name>

## Scope

## Typical paper types

## Common problem framing

## Common bottlenecks

## Common technical insights

## Standard baselines

## Standard metrics

## Common reviewer concerns

## Terms to prefer

## Terms to avoid
```

## focused_paper_patterns.md

Collapse many similar papers into patterns. Do not copy prose.

## baseline_expectations.md

List baselines and fairness checks expected by security venues.

## threat_model_notes.md

Define parties, protected assets, leakage, and assumptions typical for the direction.

## evaluation_playbook.md

Map claims to experiments and metrics.
