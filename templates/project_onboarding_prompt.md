```text
$HElicon

我现在开始一个新的论文项目。请注意：这个项目是外部项目，不要把项目事实写进 HElicon 核心记忆，除非我明确说这是长期通用经验。

项目名：<project>
目标会议：USENIX Security / NDSS / ACM CCS / IEEE S&P / uncertain
可能方向：<direction pack names>

请先不要写正文。请帮我建立：
1. project_brief.yaml；
2. 一句话故事线；
3. paper type diagnosis；
4. target-venue positioning；
5. claim-evidence map；
6. local glossary；
7. 最需要补的材料；
8. 下一步修改顺序。

我的中文说明：
<notes>

已有英文草稿：
<draft>

已有实验和证据：
<evidence>
```
